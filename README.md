## R Files

### Folder `prepare_data`

In this folder, the raw data is prepared for analysis

- `1_data_wrangling.R`: Prepare and merge raw sampling, trait, tree and environmental datasets for downstream biodiversity and modelling analyses. The script imports 2023 & 2024 sampling data, applies DNA-based species corrections, computes summary trait/body‑size tables, aggregates landscape and climate metrics
- `2_calculate_diversity_measures`: Calculate diversity measures for tree hole community data


### Folder `analysis`
- `(G)LM(M)s.R`: performs the univariate analysis for Abundance, Species richness, Biomass, extracts model summaries and partial R² values, and creates output result plots 
 Output files: results/G(LM)_results.csv 
- `NMDS_SpCompos.R`: Run NMDS on community data, test environmental drivers with fit vectors. Produce a table of envfit scores and an NMDS plot.
 Output files: results/NMDS_envfit_table.csv 
- `summary_statistics.R`: Generate summary tables and exploratory figures for tree‑hole data (counts, diversity, body size, predictor relationships, and per‑plot tree‑species composition).


### Folder `results`
- `G(LM)_results.csv`: consolidated model results (slopes, statistics, R²) generated by the `analysis/(G)LM(M)s.R` script.
- `NMDS_envfit_table.csv`: consolidated NMDS results generated by the `analysis/NMDS_SpCompos.R` script.
